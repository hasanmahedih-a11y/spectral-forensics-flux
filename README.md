## 📄 Abstract
This repository contains the official implementation of **"Spectral Forensics for Rectified Flow,"** a lightweight forensic framework designed to detect images generated by Flux.1, SDXL-Turbo, and Stable Diffusion.

Unlike traditional Deep Learning detectors ("Red AI"), this method leverages **frequency-domain physics** (RAPS, Bispectrum, Cepstrum) to identify the "spectral scar" of upsampling operations. The model achieves **93.5% accuracy** while consuming **~57× less energy** than a ResNet-50 baseline.

## 🚀 Key Features
- **Green AI:** Trains in seconds on CPU (AMD Ryzen 7), consuming only **0.000089 kWh**.
- **Physics-Based:** Extracts interpretable features like Spectral Slope ($\alpha$) and Bicoherence.
- **Zero-Shot Generalization:** Achieves **100% detection** on unseen Stable Diffusion 1.5 samples using RAPS-Only mode.
- **Privacy-First:** Lightweight enough to run locally on edge devices.

## 🛠️ Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/hasanmahedih-a11y/spectral-forensics-flux.git](https://github.com/hasanmahedih-a11y/spectral-forensics-flux.git)
   cd spectral-forensics-flux
   
**2. Install dependencies:**

pip install -r requirements.txt

**🏃 Usage**

You can reproduce the entire pipeline (Download -> Feature Extraction -> Training -> Evaluation) with a single command:
